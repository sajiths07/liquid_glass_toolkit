# liquid_glass_toolkit example

Interactive showcase for [`liquid_glass_toolkit`](https://pub.dev/packages/liquid_glass_toolkit).

- **Gallery**: surfaces, quality modes, style presets, cards with the glass
  page transition, and the legacy `LiquidGlassContainer`.
- **Controls**: buttons, icon buttons, switches, sliders, segmented control
  and text fields.
- **Overlays**: dialog, sheet, morphing menu, liquid morph and
  appear/disappear transitions.
- **Configure**: live editing of blur, opacity, tint, borders, corner
  radius, highlights, refraction, quality, motion preset and duration, dark
  mode, reduced motion and reduced transparency.

```sh
flutter run
```
